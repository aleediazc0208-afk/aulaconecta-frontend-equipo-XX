-Flujo de trabajo Git

 Observaciones de los comandos

git commit:
Al ejecutar 'git commit' se creó un nuevo nodo (commit) en el historial y la rama se movió automáticamente para apuntar a ese nuevo commit.

 git branch:
El comando 'git branch' creó una nueva rama ubicada sobre el commit donde me encontraba en ese momento, sin modificar la rama principal.

git checkout:
Con 'git checkout' cambié de una rama a otra. La rama activa cambió y el proyecto mostró los archivos correspondientes a esa rama.

git merge:
El comando 'git merge' integró los cambios realizados en una rama con otra, uniendo el historial de trabajo cuando no había conflictos.
