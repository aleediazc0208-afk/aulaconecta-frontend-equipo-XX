# AulaConecta Front-End

# Descripción del proyecto

AulaConecta es un proyecto orientado al desarrollo del front-end de una plataforma educativa. Este repositorio se crea como evidencia del taller de Git y GitHub, con el propósito de aplicar buenas prácticas de documentacion y el trabajo colaborativo antes de iniciar el desarrollo del software.



# Problema que resuelve y objetivo del front-end:

Actualmente, el proyecto requiere una estructura organizada para facilitar el trabajo colaborativo entre los integrantes del equipo. El objetivo del front-end es desarrollar una interfaz clara y responsive que permita a los usuarios interactuar con la plataforma AulaConecta de forma sencilla y eficiente.



# Alcance inicial

En esta primera etapa se definirá la estructura del proyecto y la documentación necesaria para el desarrollo del front-end los cuales son:

- Página de inicio.
- Inicio de sesión.
- Registro de usuarios.
- Panel principal.
- Navegación entre las diferentes secciones.

# Acuerdo de trabajo

Como equipo se acordó:

- Mantener la rama `main` únicamente para la versión estable.
- Realizar todos los cambios en la rama `feature-presentacion`.
- Escribir mensajes de commit claros y descriptivos.
- Revisar los cambios mediante un Pull Request antes de fusionarlos.
- Corregir las observaciones realizadas durante la revisión antes de aprobar la integración.



# Criterios de calidad

Antes de fusionar cualquier contribución se verificará que:

1. La documentación esté completa.
2. No existan errores de ortografía.
3. Los commits tengan mensajes claros y descriptivos.
4. No se publiquen datos sensibles.
5. Los cambios hayan sido revisados y aprobados por otro integrante del equipo.
